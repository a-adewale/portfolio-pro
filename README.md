# Adewale Adeogun — Software Engineering Portfolio

The portfolio website and its Vercel serverless APIs are in [`adewales_portfolio/`](adewales_portfolio/).

- [Live site](https://adewalesportfolio.vercel.app/)
- [Project documentation](adewales_portfolio/README.md)

To deploy from this repository on Vercel, set the project's **Root Directory** to `adewales_portfolio`. API secrets belong in Vercel environment variables; local `.env` files are ignored by Git.
